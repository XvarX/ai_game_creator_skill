## Bug报告规范

每个Bug报告应包含：

**基本信息**
- [ ] Bug标题清晰
- [ ] 严重程度标注（严重/主要/次要）
- [ ] 发现版本号
- [ ] 测试环境信息

**复现信息**
- [ ] 详细复现步骤
- [ ] 预期行为描述
- [ ] 实际行为描述
- [ ] 复现概率（100%/偶发）

**辅助信息**
- [ ] 截图或视频
- [ ] 日志文件
- [ ] 错误信息
- [ ] 相关设计文档引用

### 严重程度定义

**严重（Critical）**：
- 游戏崩溃或无法启动
- 核心功能完全无法使用
- 数据丢失或损坏
- 进度无法保存

**主要（Major）**：
- 重要功能异常但可绕过
- 明显影响体验的问题
- 性能严重不达标
- 明显的显示错误

**次要（Minor）**：
- 轻微的UI问题
- 不影响体验的小瑕疵
- 文案错误
- 优化建议
