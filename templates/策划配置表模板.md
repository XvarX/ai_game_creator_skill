# 策划配置表模板

> **用途**：此模板用于创建游戏数值参数和数据配置表
> **位置**：`planner_config/` 文件夹
> **创建者**：执行策划
> **使用者**：程序员（读取CSV实现功能）

---

## 📋 配置表说明

### 什么是配置表？

配置表（`planner_config/`）是存放游戏数值参数和数据配置的专用文件夹，使用**CSV格式**，策划直接编辑，程序直接读取。

**优点**：
- ✅ 简单直接，一个文件搞定
- ✅ 可用文本编辑器或Excel编辑
- ✅ 版本控制友好（diff清晰）
- ✅ 跨平台兼容

### 何时创建配置表？

当设计文档中包含以下内容时，应创建对应的配置表：
- ✅ 数值参数（HP、MP、伤害值、经验值等）
- ✅ 成长曲线（等级提升、XP表格）
- ✅ 物品/装备数据
- ✅ 技能/能力定义
- ✅ 敌人/Boss数据
- ✅ 掉落率/奖励配置

### 配置表文件夹结构（根据实际项目动态创建）

**⚠️ 重要原则**：
- 配置表分类应该**根据你的 `docs/模块拆解_v1.md` 中的模块来决定**
- 每个系统有配置参数时，才创建对应的CSV文件
- 如果参数很少，可以直接放在 `planner_config/` 根目录

**如何决定文件夹结构**：

1. **查看你的模块拆解文档**（`docs/模块拆解_v1.md`）
2. **识别哪些系统有可配置参数**
3. **按模块/系统创建文件夹**（如果需要的话）

**示例对比**：

**简单游戏（贪吃蛇）** - 参数少，直接放根目录：
```
planner_config/
└── game_params.csv          # 所有参数在一个文件
```

**中等游戏（平台跳跃）** - 按模块划分：
```
planner_config/
├── character/               # 角色模块参数
│   └── character_stats.csv
├── level/                   # 关卡模块参数
│   └── level_config.csv
└── gameplay/                # 游戏核心参数
    └── game_params.csv
```

**复杂游戏（RPG）** - 每个系统独立文件夹：
```
planner_config/
├── balance/                 # 平衡参数
│   ├── 角色属性表.csv
│   └── 伤害系数表.csv
├── items/                   # 物品装备
│   ├── 武器配置表.csv
│   └── 防具配置表.csv
├── skills/                  # 技能系统
│   └── 技能配置表.csv
├── enemies/                 # 敌人系统
│   └── 敌人配置表.csv
└── gameplay/                # 游戏参数
    └── 游戏参数表.csv
```

**总结**：
- ✅ 根据实际游戏的模块拆解来决定结构
- ✅ 参数少时简化，参数多时细分
- ❌ 不要套用固定的RPG分类模板

## 📐 CSV格式规范

### 基本格式

**编码**：UTF-8
**第一行**：列名
**第二行起**：数据
**分隔符**：逗号（,）

### 列命名规范

- 使用清晰的中文列名
- 第一行为列名
- 第二行开始为数据
- 避免空行
- 避免逗号（如需包含逗号，用引号包裹）

### 数据类型

| 列类型 | 说明 | 示例 |
|--------|------|------|
| ID | 唯一标识符 | W001, E001, S001 |
| 名称 | 显示名称 | 木剑, 火球术 |
| 数值 | 整数或小数 | 100, 1.5 |
| 百分比 | 小数形式（0-1） | 0.05 = 5% |
| 枚举 | 固定选项 | 单手/双手/魔法 |

## 💡 使用指南

### 对于执行策划

**创建配置表的工作流程**：

1. **查看模块拆解**：阅读 `docs/模块拆解_v1.md`，了解项目有哪些模块
2. **识别配置需求**：从系统设计文档中找出需要配置的数值参数
3. **决定文件夹结构**：
   - 参数少（<5个配置）→ 直接放 `planner_config/` 根目录
   - 参数中等（5-15个）→ 按模块分文件夹
   - 参数多（>15个）→ 按系统分文件夹
4. **创建CSV文件**：使用文本编辑器（VS Code）或Excel
5. **添加说明**：在文件开头用 `#` 添加注释（单位、公式、相关文档）
6. **使用UTF-8编码保存**

**编辑工具选择**：

| 工具 | 优点 | 缺点 |
|------|------|------|
| VS Code | 语法高亮、Git友好 | 需要手动对齐 |
| Excel | 界面友好、支持公式 | 需另存为CSV UTF-8 |
| 记事本 | 简单快捷 | 无格式提示 |

**推荐**：VS Code + CSV插件，或Excel（编辑后另存为CSV UTF-8）

**CSV格式注意事项**：
- ✅ 使用UTF-8编码
- ✅ 第一行为列名
- ✅ 逗号分隔
- ✅ 百分比用小数表示（0.05 = 5%）
- ❌ 避免在数值中包含逗号
- ❌ 避免空行

---

### 对于程序员

**读取配置表**：

```python
import csv
from pathlib import Path
from typing import List, Dict

def load_config(csv_name: str) -> List[Dict]:
    """加载配置表（通用函数）"""
    csv_path = Path(f"planner_config/{csv_name}")

    with open(csv_path, 'r', encoding='utf-8') as f:
        reader = csv.DictReader(f)
        return list(reader)

# 使用示例（根据实际项目调整）
params = load_config("game_params.csv")
for row in params:
    print(f"{row['参数名']}: {row['数值']} {row['单位']}")
```

**推荐使用 config_loader.py**：

项目提供了通用配置加载工具：[scripts/config_loader.py](../scripts/config_loader.py)

```python
from code.common.config_loader import load_csv, load_csv_typed, index_by_field

# 加载配置
params = load_csv("game_params.csv", config_root="planner_config")

# 带类型转换
type_map = {"数值": float}
params = load_csv_typed("game_params.csv", type_map, config_root="planner_config")

# 创建索引（快速查找）
params_index = index_by_field(params, "参数名")
fps = params_index.get("目标帧率")
```

**注意事项**：
- ✅ CSV文件使用UTF-8编码
- ✅ 第一行为列名，从第二行开始读取
- ✅ 百分比以小数形式存储（0.05 = 5%）
- ✅ 在代码注释中标注数据来源
- ✅ 游戏初始化时一次性加载所有配置表

## ⚠️ 注意事项

1. **版本管理**：
   - 配置表使用版本号（_v1, _v2）
   - 更新时删除旧版本
   - 保持单一数据源

2. **数据一致性**：
   - 配置表数据要与设计文档一致
   - 修改时同步更新配置表和相关文档
   - 避免数据冲突

3. **格式规范**：
   - 使用UTF-8编码
   - 第一行为列名
   - 避免空行和特殊字符
   - 百分比用小数表示

4. **性能考虑**：
   - 配置表应在游戏初始化时加载
   - 避免运行时频繁读取文件
   - 可考虑预加载到内存字典

5. **协作工作流**：
   - 策划编辑CSV文件
   - 提交到Git
   - 程序拉取后直接使用
   - 版本控制清晰可见
