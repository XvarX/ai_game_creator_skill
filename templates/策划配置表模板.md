# 策划配置表模板

> **用途**：此模板用于创建游戏数值参数和数据配置表
> **位置**：`planner_config/` 文件夹
> **创建者**：执行策划
> **使用者**：程序员（读取CSV实现功能）

---

## 📋 配置表说明

### 什么是配置表？

配置表（`planner_config/`）是存放游戏数值参数和数据配置的专用文件夹，使用**CSV格式**，策划直接编辑，程序直接读取。

**优点**：
- ✅ 简单直接，一个文件搞定
- ✅ 可用文本编辑器或Excel编辑
- ✅ 版本控制友好（diff清晰）
- ✅ 跨平台兼容

### 何时创建配置表？

当设计文档中包含以下内容时，应创建对应的配置表：
- ✅ 数值参数（HP、MP、伤害值、经验值等）
- ✅ 成长曲线（等级提升、XP表格）
- ✅ 物品/装备数据
- ✅ 技能/能力定义
- ✅ 敌人/Boss数据
- ✅ 掉落率/奖励配置

### 配置表文件夹结构

```
planner_config/
├── balance/        # 游戏平衡参数
│   ├── 角色属性表.csv
│   ├── 伤害系数表.csv
│   └── 等级成长表.csv
├── items/          # 物品和装备数据
│   ├── 装备配置表.csv
│   └── 道具配置表.csv
├── skills/         # 技能和能力数据
│   └── 技能配置表.csv
├── enemies/        # 敌人和Boss数据
│   └── 敌人配置表.csv
└── gameplay/       # 游戏参数
    └── 游戏参数表.csv
```

## 📐 CSV格式规范

### 基本格式

**编码**：UTF-8
**第一行**：列名
**第二行起**：数据
**分隔符**：逗号（,）

### 列命名规范

- 使用清晰的中文列名
- 第一行为列名
- 第二行开始为数据
- 避免空行
- 避免逗号（如需包含逗号，用引号包裹）

### 数据类型

| 列类型 | 说明 | 示例 |
|--------|------|------|
| ID | 唯一标识符 | W001, E001, S001 |
| 名称 | 显示名称 | 木剑, 火球术 |
| 数值 | 整数或小数 | 100, 1.5 |
| 百分比 | 小数形式（0-1） | 0.05 = 5% |
| 枚举 | 固定选项 | 单手/双手/魔法 |

## 💡 使用指南

### 对于执行策划

**创建配置表**：

1. **识别需要配置表的数据**（从设计文档中）
2. **创建CSV文件**：在 `planner_config/[category]/` 创建 `.csv` 文件
3. **编辑CSV**：
   - 用文本编辑器（VS Code等）或Excel
   - 第一行写列名
   - 第二行开始写数据
4. **添加注释**：在文件开头用 `#` 添加说明（可选）
5. **使用UTF-8编码保存**

**编辑工具选择**：

| 工具 | 优点 | 缺点 |
|------|------|------|
| VS Code | 语法高亮、Git友好 | 需要手动对齐 |
| Excel | 界面友好、支持公式 | 需另存为CSV UTF-8 |
| 记事本 | 简单快捷 | 无格式提示 |

**推荐**：VS Code + CSV插件，或Excel（编辑后另存为CSV UTF-8）

**CSV格式注意事项**：
- ✅ 使用UTF-8编码
- ✅ 第一行为列名
- ✅ 逗号分隔
- ✅ 百分比用小数表示（0.05 = 5%）
- ❌ 避免在数值中包含逗号
- ❌ 避免空行

### 对于程序员

**读取配置表**：

```python
import csv
from pathlib import Path
from typing import List, Dict

def load_character_attributes():
    """加载角色属性表"""
    csv_path = Path("planner_config/balance/角色属性表.csv")

    with open(csv_path, 'r', encoding='utf-8') as f:
        reader = csv.DictReader(f)
        attributes = list(reader)

    # 转换数据类型
    for attr in attributes:
        attr['等级'] = int(attr['等级'])
        attr['HP'] = int(attr['HP'])
        attr['MP'] = int(attr['MP'])
        attr['攻击力'] = int(attr['攻击力'])
        attr['暴击率'] = float(attr['暴击率'])

    return attributes

# 使用示例
attributes = load_character_attributes()
level_3_stats = attributes[2]  # 等级3的属性
print(f"HP: {level_3_stats['HP']}, 攻击力: {level_3_stats['攻击力']}")
```

**游戏初始化时加载**：

```python
class GameConfig:
    def __init__(self):
        self.character_attributes = self.load_csv('balance/角色属性表.csv')
        self.equipment = self.load_csv('items/装备配置表_武器.csv')
        self.skills = self.load_csv('skills/技能配置表.csv')

    def load_csv(self, path):
        """通用CSV加载函数"""
        csv_path = Path(f"planner_config/{path}")
        with open(csv_path, 'r', encoding='utf-8') as f:
            reader = csv.DictReader(f)
            return list(reader)

# 使用
config = GameConfig()
print(config.character_attributes)
```

**注意事项**：
- ✅ CSV文件使用UTF-8编码
- ✅ 第一行为列名，从第二行开始读取
- ✅ 百分比以小数形式存储（0.05 = 5%）
- ✅ 在代码注释中标注数据来源
- ✅ 游戏初始化时一次性加载所有配置表

## 📁 常见配置表类型

### balance/ (平衡参数)

- `角色属性表.csv` - 角色基础属性和成长
- `伤害系数表.csv` - 伤害计算系数
- `等级成长表.csv` - 升级经验和奖励
- `经济系数表.csv` - 金币获取和消耗

### items/ (物品装备)

- `装备配置表_武器.csv` - 武器参数
- `装备配置表_防具.csv` - 防具参数
- `道具配置表.csv` - 消耗品和材料

### skills/ (技能能力)

- `技能配置表.csv` - 技能参数和效果
- `被动技能表.csv` - 被动技能效果
- `技能树配置.csv` - 技能解锁条件

### enemies/ (敌人Boss)

- `敌人配置表.csv` - 敌人属性和行为
- `Boss配置表.csv` - Boss数据和机制
- `怪物掉落表.csv` - 怪物掉落物品

### gameplay/ (游戏参数)

- `游戏参数表.csv` - 游戏核心参数
- `UI参数表.csv` - 界面布局参数
- `控制参数表.csv` - 输入控制参数

## ⚠️ 注意事项

1. **版本管理**：
   - 配置表使用版本号（_v1, _v2）
   - 更新时删除旧版本
   - 保持单一数据源

2. **数据一致性**：
   - 配置表数据要与设计文档一致
   - 修改时同步更新配置表和相关文档
   - 避免数据冲突

3. **格式规范**：
   - 使用UTF-8编码
   - 第一行为列名
   - 避免空行和特殊字符
   - 百分比用小数表示

4. **性能考虑**：
   - 配置表应在游戏初始化时加载
   - 避免运行时频繁读取文件
   - 可考虑预加载到内存字典

5. **协作工作流**：
   - 策划编辑CSV文件
   - 提交到Git
   - 程序拉取后直接使用
   - 版本控制清晰可见
