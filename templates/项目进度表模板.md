## 💡 使用指南

### 对于主策划
- 根据模块拆解文档创建模块和系统
- 设置合理的优先级
- 更新设计文档状态

### 对于执行策划
- 完成设计后更新"设计"列状态
- 确保每个功能都有详细的RAG关键字

### 对于程序员
1. 查看"整体进度"了解当前阶段
2. 查看"模块进度"了解哪些模块已搭建
3. 按**优先级**从P0开始实现
4. 在"功能明细"中找到要实现的功能
5. 使用**RAG查询关键字**查询需求细节：
   ```bash
   python rag/scripts/rag_query.py "关键字1 关键字2"
   ```
6. 实现功能后更新"架构"和"实现"列状态
7. 先搭建模块架构，再实现具体功能

**⚠️ 代码文件放置约束**：
- ✅ **所有代码文件必须放在 `code/` 目录内**
- ✅ 包括：`main.py`, `config.py`, `settings.py`, `constants.py` 等
- ❌ **禁止**在项目根目录创建任何代码文件
- ✅ 入口文件位置：`code/main.py`（而非根目录的 `main.py`）
- ✅ 运行命令：`python code/main.py` 或 `python -m code.main`

### 对于测试员
- 查看"测试"列，找到待测试的功能
- 使用RAG查询关键字了解功能预期行为
- 完成测试后更新"测试"列状态

### 关键工作流

**程序员实现流程**：
```
1. 查看进度表 → 找到P0优先级的未完成功能
2. 复制RAG关键字 → 查询RAG获取需求
3. 搭建代码架构（如果模块未搭建）
4. 实现功能代码
5. 更新进度表状态
6. 继续下一个功能
```

**模块搭建优先级**：
1. 先完成所有P0模块的架构搭建
2. 再完成P0模块内P0功能的实现
3. 依次完成P1、P2...
